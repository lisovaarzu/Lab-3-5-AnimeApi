## О проекте

- **API:** Jikan API v4 — открытое API для аниме-базы MyAnimeList
- **Функционал:**
    - Просмотр списка аниме
    - Поиск аниме по названию
    - Просмотр детальной информации об аниме
    - Добавление/удаление аниме в избранное (сохраняется в Room)

## Домашнее задание №3

### Реализовано:
- Два экрана: список аниме с поиском и детальная информация
- Navigation Compose для навигации между экранами
- Retrofit для сетевых запросов
- Coroutines для асинхронности
- Stateless экраны (получают UiState и колбэки из ViewModel)

### UI-состояния:
- Loading — индикатор загрузки
- Error — сообщение об ошибке с кнопкой Retry
- Empty — сообщение об отсутствии результатов
- Success — отображение данных

### Особенности:
- Поиск с дебаунсом 500 мс
- Отмена предыдущих поисковых запросов
- Повторный запрос с задержкой при ошибке 429 (rate limit)

## Домашнее задание №4

### Hilt (Dependency Injection):
- `@HiltAndroidApp` в Application
- `@AndroidEntryPoint` в Activity
- `@HiltViewModel` в ViewModel

### DI-модули:
- **NetworkModule** — Retrofit, OkHttp, JikanApi
- **DatabaseModule** — Room база и DAO
- **RepositoryModule** — биндинг репозитория

### Room (локальная БД):
- Таблица `favourites_anime` для хранения избранного
- Поля: id (первичный ключ), title, imageUrl, episodes, rating, year
- Операции: добавление, удаление, получение списка

### Функционал избранного:
- Добавление/удаление нажатием на звездочку (★/☆)
- Данные сохраняются после перезапуска приложения
- UI обновляется мгновенно
